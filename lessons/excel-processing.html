4.5.1 Build a frequency table in Excel

Turn a raw list of numbers into a frequency table with a running total.

Steps

  1. Type the raw data down one column, for example resistor readings in A2:A21.
  2. In another column, list the classes or values you want to count (e.g. class midpoints or exact values).
  3. Next to each class, use =COUNTIF(A$2:A$21, C2) for exact values, or the array formula =FREQUENCY(A2:A21, bins) for grouped classes.
  4. Add a cumulative frequency column with a running total: =SUM(D$2:D2) copied down.

4.5.2 Bar chart & pie chart

Both charts start the same way — the chart type is the only real choice.

Steps

  1. Select the class/value column and the frequency column together.
  2. Go to the Insert tab.
  3. In the Charts group, pick Bar/Column chart for a bar chart (gaps between bars), or Pie chart to show parts of the whole.
  4. Use Chart Design → Add Chart Element to add a title and axis/data labels.

4.5.3 Histogram & ogive

A histogram shows the shape of grouped data; an ogive shows the running total.

Steps

  1. Build the grouped frequency table first (see 4.5.1), using class boundaries as the bin edges.
  2. Histogram: select the class and frequency columns → Insert → Insert Statistic Chart → Histogram (or make a column chart and set Gap Width to 0% in Format Data Series, since histogram bars must touch).
  3. Ogive: select the upper class boundary and cumulative frequency columns → Insert → Line chart. The ogive always starts at 0 and only goes up.

🎮 Try it yourself

Open Excel (or a free alternative like Google Sheets) and work through this checklist with your own data.

  • Type 15–20 raw values into column A.
  • Build a frequency table with COUNTIF or FREQUENCY.
  • Add a cumulative frequency column with a running SUM.
  • Insert a bar chart from your frequency table.
  • Insert a pie chart from a "share of total" table.
  • Turn your frequency table into a histogram (gap width 0%).
  • Turn your cumulative table into an ogive (line chart).
  • Calculate mean, mode, median, range, variance and standard deviation with formulas.
Why use Excel instead of doing it by hand?

Excel formulas update automatically when the data changes, so you can check your by-hand answers instantly and explore "what if a value changes?" without redoing every calculation.
