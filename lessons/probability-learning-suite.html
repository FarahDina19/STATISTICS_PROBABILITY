📘 Binomial Distribution

Definition: Counting successes in a fixed number of independent trials.

Use binomial when:
  • ✓ Fixed number of trials (n)
  • ✓ Two outcomes per trial (success/failure)
  • ✓ Same probability each trial (p)
  • ✓ Independent trials

🏀 Example 1: Basketball Free Throws

Scenario: Player makes 70% of free throws, takes 10 shots
P(X = k) = ¹⁰Cₖ × (0.7)^k × (0.3)^(10-k)

Key Concepts:

  • n = 10 (number of trials)
  • p = 0.7 (success probability)
  • k = number of successes
  • Expected value: E(X) = 10 × 0.7 = 7 baskets

🏭 Example 2: Quality Control

Scenario: Factory produces 20 light bulbs, 5% defective rate
P(X = 1) = ²⁰C₁ × (0.05)¹ × (0.95)¹⁹

Find probability of exactly 1 defective bulb in batch of 20.

🪙 Example 3: Coin Flips (Simplest Case)

Scenario: Flip fair coin 5 times, find P(exactly 3 heads)
P(X = 3) = ⁵C₃ × (0.5)³ × (0.5)² = 10 × 0.125 × 0.25 = 0.3125

Meaning: In 31.25% of 5-flip experiments, exactly 3 heads appear.

📊 Formula Breakdown

Component Meaning Example
ⁿCₖ Ways to arrange k successes ¹⁰C₇ = 120 ways
p^k Probability of successes (0.7)⁷
(1-p)^(n-k) Probability of failures (0.3)³
E(X) = np Expected value 10 × 0.7 = 7

📗 Normal Distribution

Definition: A bell-shaped curve describing continuous measurements.

Use normal when:
  • 📏 Measuring something (height, weight, time)
  • 📈 Data follows bell shape
  • 🔄 Symmetric around mean
  • 🎯 Most values in middle, fewer at extremes

📚 Example 1: Test Scores

Data: Mean = 70%, SD = 10% Question: What % scored between 60% and 80%?
z₁ = (60-70)/10 = -1
z₂ = (80-70)/10 = 1
P(60≤X≤80) = Φ(1) - Φ(-1) = 0.6826

Answer: About 68.26% scored between 60% and 80%

🚚 Example 2: Delivery Time

Data: Average = 30 min, SD = 5 min Question: Probability of delivery ≤ 35 minutes?
z = (35-30)/5 = 1
P(X ≤ 35) = Φ(1) = 0.8413

Answer: 84.13% of deliveries arrive by 35 minutes

📏 Example 3: Height Distribution

Data: Mean = 165 cm, SD = 8 cm Question: % taller than 173 cm?
z = (173-165)/8 = 1
P(X > 173) = 1 - Φ(1) = 0.1587

Answer: About 15.87% are taller than 173 cm

🌟 The Magic 68-95-99.7 Rule

Within ±1σ: 68% of data
Within ±2σ: 95% of data
Within ±3σ: 99.7% of data

Use this for quick mental estimates!

📐 Z-Score: The Translator Tool

What is a Z-Score?

Definition: Tells you how many standard deviations a value is away from the mean.

z = (x - μ) / σ

🔄 The Translation Process

Original: Score 75 out of 100 (doesn't tell us much!)

Translation: Mean = 70, SD = 5
z = (75 - 70) / 5 = 1

Meaning: 1 standard deviation ABOVE the mean
Interpretation: Your score is 1 SD better than average

Why Z-Scores Matter

❌ Problem: Can't compare different scales directly
  • Test 1: Score 75 out of 100
  • Test 2: Score 45 out of 50
  • Which is better? Hard to tell!
✅ Solution: Use Z-Scores
  • Test 1: z = (75-70)/5 = 1.0
  • Test 2: z = (45-40)/4 = 1.25
  • Test 2 is better! (higher z-score)

Reading the Z-Table

z value Φ(z) (left area) Meaning
0.00 0.5000 50% below mean
1.00 0.8413 84.13% below this point
-1.00 0.1587 15.87% below this point
2.00 0.9772 97.72% below this point
💡 KEY RULE: Table gives LEFT area always!
  • For right area: 1 - Φ(z)
  • For area between: Φ(z₂) - Φ(z₁)

⚠️ Common Mistakes to Avoid

❌ Mistake 1: Using σ² Instead of σ

WRONG: z = (x - μ) / σ²
CORRECT: z = (x - μ) / σ
Hint: If N(30, 25), then σ² = 25, so σ = √25 = 5

❌ Mistake 2: Not Adding Probabilities for Ranges

WRONG: P(X ≤ 3) = P(X = 3)
CORRECT: P(X ≤ 3) = P(X=0) + P(X=1) + P(X=2) + P(X=3)
Remember: "At most 3" means 0, 1, 2, AND 3

❌ Mistake 3: Reading Normal Table Wrong

WRONG: Using right-tail area when table gives left
CORRECT: Φ(z) is ALWAYS left area
For right area: 1 - Φ(z)
Example: Φ(1) = 0.8413 means 84.13% to the left, 15.87% to the right

❌ Mistake 4: Confusing p and (1-p)

WRONG: Using success probability for failures
CORRECT: P(X=k) = ⁿCₖ × p^k × (1-p)^(n-k)
Use p for successes, (1-p) for failures
Check: If p = 0.7, then 1-p = 0.3

❌ Mistake 5: Using Binomial When Events Are Dependent

WRONG: Drawing cards without replacement treated as binomial
CORRECT: Check if each trial affects the next
Examples:
  • ✅ Coin flips (independent)
  • ✅ Drawing WITH replacement (independent)
  • ❌ Drawing WITHOUT replacement (dependent)

📋 Complete Formula Reference

Binomial Formulas

Main: P(X = k) = ⁿCₖ × p^k × (1-p)^(n-k)
Expected Value: E(X) = np
Variance: Var(X) = np(1-p)
Standard Deviation: SD = √[np(1-p)]
Combination: ⁿCₖ = n! / [k!(n-k)!]

Normal Formulas

Z-Score: z = (x - μ) / σ
Cumulative Probability: P(X ≤ x) = Φ(z)
Right Tail: P(X > x) = 1 - Φ(z)
Range Probability: P(a ≤ X ≤ b) = Φ(z_b) - Φ(z_a)

When to Use Each Formula

Question Formula Example
Exactly k successes P(X=k) = ⁿCₖ p^k (1-p)^(n-k) 3 heads in 5 flips
At most k Sum P(X=0) to P(X=k) 0-3 baskets in 10 shots
Convert to z-score z = (x-μ)/σ Score of 75 vs mean 70
Probability ≤ value Φ(z) from table Height ≤ 170 cm
