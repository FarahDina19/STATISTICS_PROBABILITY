Visual Guide for Understanding Binomial & Normal Distributions

📊 Binomial Distribution - EASY EXPLANATION

What is Binomial? 🎯

Simple Definition: Counting successes in a fixed number of independent trials.

Think of it this way: You're counting something with YES/NO answers:
  • ✅ YES = Success
  • ❌ NO = Failure
  • You do it a FIXED NUMBER OF TIMES

🏀 Real Example 1: Basketball Free Throws

A basketball player makes 70% of free throws.

  • 💪 She takes 10 shots (fixed n = 10)
  • 🎯 Each shot: MAKE (success, p = 0.7) or MISS (failure, 1-p = 0.3)
  • 🤔 Question: How many baskets will she probably make?
P(X = k) = ¹⁰Cₖ × (0.7)^k × (0.3)^(10-k)
Expected: 10 × 0.7 = 7 baskets (on average)

🏭 Real Example 2: Quality Control

A factory makes light bulbs with 5% defective rate.

  • 📦 Check 20 bulbs (n = 20)
  • 🔴 Each bulb: GOOD (success) or DEFECTIVE (failure, p = 0.05)
  • ❓ Question: What's probability of exactly 1 defective?
P(X = 1) = ²⁰C₁ × (0.05)¹ × (0.95)¹⁹

🪙 Simplest Example: Coin Flips

Flip fair coin 5 times Find: P(exactly 3 heads) n = 5 (trials) p = 0.5 (probability of heads) k = 3 (wanted heads) P(X=3) = ⁵C₃ × (0.5)³ × (0.5)² = 10 × 0.125 × 0.25 = 0.3125 (31.25% chance) Meaning: In many experiments of 5 flips, about 31% will have exactly 3 heads
🤖 Diagram prompt: Exactly 3 heads

Show all 32 equally likely sequences of 5 independent fair coin flips. Label each coin H or T and highlight the 10 sequences with exactly 3 heads. Show ⁵C₃ = 10 and P(X=3) = 10/32 = 0.3125 (31.25%). Use gold for heads and silver for tails, with text labels.

📖 The Formula Breakdown

Symbol Meaning Example (basketball)
n Number of trials 10 shots
p Probability of success 0.7 (70% make)
k Number of successes 7 baskets
ⁿCₖ Ways to arrange k successes ¹⁰C₇ = 120 ways
p^k Prob. of k successes (0.7)⁷
(1-p)^(n-k) Prob. of failures (0.3)³

🔔 Normal Distribution - EASY EXPLANATION

What is Normal Distribution? 📊

Simple Definition: A bell-shaped curve that describes measurements.

Use it when:
  • 📏 Measuring something (height, weight, time)
  • 📈 Data makes a bell shape
  • 🔄 Symmetric (same left and right)
  • 🎯 Most values in the middle, fewer at extremes

📚 Real Example 1: Test Scores

Class test scores follow normal distribution:

  • 📊 Average (mean) = 70%
  • 📉 Spread (SD) = 10%
  • ❓ Question: What % scored between 60% and 80%?
ANSWER: About 68% Why? Because 60% = 70% - 10% (one SD below) And 80% = 70% + 10% (one SD above) One SD on each side of mean = 68% of data

🚚 Real Example 2: Delivery Time

Pizza delivery time:

  • ⏱️ Average = 30 minutes
  • 📊 Standard deviation = 5 minutes
  • ❓ Question: Probability of delivery in ≤ 35 minutes?
z = (35 - 30) / 5 = 1
Result: 84.13% of deliveries arrive by 35 minutes
🤖 Diagram prompt: Normal cumulative probability

Shade the area to the left of each cutoff. Label P(X≤35) = P(Z≤1) ≈ 0.8413: about 84.13% arrive by 35 minutes. Explain that probability is shaded area, not curve height.

📏 Real Example 3: Height

Student heights:

  • 📏 Average = 165 cm
  • 📊 SD = 8 cm
  • ❓ Question: % taller than 173 cm?
z = (173 - 165) / 8 = 1 P(X > 173) = 1 - 0.8413 = 0.1587 Answer: About 15.87% are taller

🌟 The Magic 68-95-99.7 Rule

Within 1 standard deviation: 68% of data ▒▒▒▒▒▒▒▒▒ 68% ▒▒▒▒▒▒▒▒▒ μ-σ μ μ+σ Within 2 standard deviations: 95% of data ▒▒▒▒▒▒▒▒▒▒▒▒▒ 95% ▒▒▒▒▒▒▒▒▒▒▒▒▒ μ-2σ μ μ+2σ Within 3 standard deviations: 99.7% of data ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ 99.7% ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ μ-3σ μ μ+3σ
Example: Test scores: μ=70, σ=10
  • 68% score between 60-80
  • 95% score between 50-90
  • 99.7% score between 40-100

📐 Z-Score: The Translator Tool

What is a Z-Score? 🔧

Definition: A z-score tells you how many standard deviations a value is away from the mean.

Think of it as: A "translation" from your original units to "how many SDs"

🔄 The Translation Process

ORIGINAL QUESTION: Test score = 75 out of 100 Doesn't tell us much by itself! TRANSLATION: Mean = 70, SD = 5 z = (75 - 70) / 5 = 1 MEANING: z = 1 → "1 standard deviation ABOVE the mean" THIS MEANS: ✓ Your score is 1 SD better than average ✓ 84.13% of people score below you

Why Z-Scores Matter? 🎯

Compare apples to apples:

  • ❌ Test 1: Score 75 out of 100
  • ❌ Test 2: Score 45 out of 50
  • 🤔 Which is better? Can't compare directly!

✅ Solution: Use z-scores!

  • Test 1: z = (75-70)/5 = 1.0
  • Test 2: z = (45-40)/4 = 1.25
  • ✓ Test 2 is better (higher z-score)

📊 Z-Score Table (Φ(z))

After you calculate z, you use a table to find the probability:

z value Φ(z) (left area) Meaning
0.00 0.5000 50% below mean
1.00 0.8413 84.13% below this point
-1.00 0.1587 15.87% below this point
2.00 0.9772 97.72% below this point
💡 KEY INSIGHT: The table gives you the area to the LEFT of z
  • For right area: 1 - Φ(z)
  • For area between: Φ(z₂) - Φ(z₁)

⚠️ Common Mistakes - Learn to AVOID Them

❌ MISTAKE 1: Using σ² Instead of σ

WRONG:
z = (x - μ) / σ²
CORRECT:
z = (x - μ) / σ
Hint: The second number is VARIANCE (σ²)
  • If N(30, 25), then σ² = 25
  • You need σ = √25 = 5

❌ MISTAKE 2: Forgetting to Add Probabilities

WRONG:
P(X ≤ 3) = P(X = 3)
CORRECT:
P(X ≤ 3) = P(X=0) + P(X=1) + P(X=2) + P(X=3)
Remember: "At most 3" means 0, 1, 2, AND 3
🤖 Diagram prompt: Cumulative vs individual probability

Use text labels as well as colour.

❌ MISTAKE 3: Reading Normal Table Wrong

WRONG:
Using right-tail area when table gives left area
CORRECT:
Φ(z) is ALWAYS left area
For right area: 1 - Φ(z)
For middle area: Φ(z₂) - Φ(z₁)
The table always shows area to the LEFT
  • Φ(1) = 0.8413 means 84.13% to the left
  • So 15.87% to the right

❌ MISTAKE 4: Confusing p and (1-p)

WRONG:
Using success probability when you need failure probability
CORRECT:
P(X = k) = ⁿCₖ × p^k × (1-p)^(n-k)
                        ↑          ↑ successes
                        └─ failures (1-p)
Tip: If p = 0.7 (success)
  • Then 1-p = 0.3 (failure)

❌ MISTAKE 5: Forgetting Independence

WRONG:
Using binomial when events are NOT independent
CORRECT:

Check: Does each trial affect the next?

Examples:
  • ✅ Drawing WITH replacement (binomial OK)
  • ❌ Drawing WITHOUT replacement (binomial NOT OK)
  • ✅ Coin flips (independent)
  • ❌ Drawing cards from deck without replacing (dependent)

📋 All Formulas Summary

Binomial Formulas

Main Formula: P(X = k) = ⁿCₖ × p^k × (1-p)^(n-k)
Expected Value: E(X) = np
Variance: Var(X) = np(1-p)
Standard Deviation: SD = √[np(1-p)]
Combination: ⁿCₖ = n! / [k!(n-k)!]

Normal Formulas

Z-Score: z = (x - μ) / σ
Cumulative Probability: P(X ≤ x) = Φ(z)
Right Tail: P(X > x) = 1 - Φ(z)
Range Probability: P(a ≤ X ≤ b) = Φ(z_b) - Φ(z_a)

When to Use Each Formula

Question Type Formula Example
Exactly k successes P(X=k) = ⁿCₖ p^k (1-p)^(n-k) 3 heads in 5 flips
At most k successes Sum P(X=0) to P(X=k) 0-3 baskets in 10 shots
Average successes E(X) = np Expected heads in 5 flips
Convert measurement to z z = (x-μ)/σ Score of 75 vs mean 70
Probability ≤ value Φ(z) from table Height ≤ 170 cm
